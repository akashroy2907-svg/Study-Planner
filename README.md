# 📚 Study Planner – Java Project

## 📌 About the Project

Study Planner is a Java-based application designed to help students organize and manage their academic activities effectively. It provides an easy-to-use platform for planning study schedules, managing subjects, tracking daily tasks, and improving time management.

The main goal of this project is to increase student productivity by providing a structured way to plan studies, monitor progress, and complete academic tasks on time.

## ✨ Features

- 📅 **Study Schedule Management:** Organize daily study routines.
- 📖 **Subject Management:** Manage different subjects efficiently.
- ✅ **Task Management:** Add, update, and track study tasks.
- ⏰ **Time Management:** Plan study sessions effectively.
- 📊 **Progress Tracking:** Monitor completed and pending tasks.
- 🎨 **User-Friendly Interface:** Simple and interactive dashboard.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI:** Java Swing (if applicable)
- **IDE:** NetBeans / IntelliJ IDEA / Eclipse
- **JDK:** Java Development Kit
